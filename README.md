# MyZoomIt 2.0
给演讲者、演示者的轻巧屏幕标注小工具。

这个小工具是我一直使用的[Zoomit](https://learn.microsoft.com/zh-cn/sysinternals/downloads/zoomit) 的现代改进版，轻量、快捷键驱动。
改为使用 Windows Ink 原生控件，使其笔画流畅度、系统兼容性优异（可参考office中的绘图工具）。

主要特点：
- 兼容电磁/电容笔（如surface系列笔记本/平板）、手指触控和鼠标绘制三种方式
- 使用win ink机制，笔画平滑流畅，能方便的擦除、撤销和重复
- 适配多屏幕和windows自带的屏幕放大镜（win+加号），兼容复杂的展示环境
- 为演示者优化的极简的快捷按键操作，减少屏幕视觉干扰
- 便携版且极小体积，exe 文件约 1.5 MB
- 免费，无需注册
- C++ ，MIT协议

只支持windows系统，兼容性在windows11 x64上验证通过，配置随程序文件夹携带。

## 使用说明
运行后程序在系统托盘常驻（图标可能位于隐藏图标区）

- 按下快捷键（默认Ctrl+2，个人习惯，可修改）进行标注，再次按下或Esc退出
- 用鼠标、触控笔或触摸屏幕绘制，均支持压感效果

- 按键1~5切换标注的图形模式：
  1手写，2矩形，3椭圆，4直线，5箭头
- 亦可配合修饰键快速绘制图形：
  Ctrl矩形，Tab椭圆，Shift直线，Ctrl+Shift箭头
- 按键切换笔迹颜色，共七种：
  R红色，G绿色，B蓝色，O橙色，Y黄色，P紫色，W白色

- Ctrl+滚轮：调整笔迹粗细(4~24px，默认笔宽可在设置中调整)
- Ctrl+Z：撤销上一笔画或图形

- K：切换为纯黑背景，模拟在黑板上书写
- E：橡皮擦
- C：清空笔迹

- 退出标注会话时，自动将最终可见画面（含笔迹）复制到剪贴板，然后清空笔迹。

- 增加系统级的“鼠标强调”功能，用于打开系统设置“鼠标指针”项中的“按Ctrl显示鼠标位置”功能，能够有效引导观众注意力
- 增加“开机自动运行”功能

## 关于放大
- Ctrl+1：截图浏览与标注；快捷键可在设置中单独修改或停用。
- 进入时截取鼠标所在屏幕，默认放大 200%，初始倍率滑杆范围为 100%–400%，步长 25%。
- 浏览时移动鼠标平移画面，滚轮每格缩放 25 个百分点；点击左键、手指或电磁笔接触屏幕进入标注；这次接触仅切换状态，抬起后再次按下才开始绘制。
- 标注时固定倍率和视口；右键返回浏览，保留笔迹，截图与笔迹一起缩放。
- Esc 或再次按快捷键结束会话，并将当前视口复制到剪贴板。橡皮擦状态下 Esc 先恢复画笔；浏览状态下 Esc 直接退出。
- 实时标注仍可配合 Windows 自带放大镜使用。

## 致谢
- 鼠标和触控屏绘制的算法借鉴了 perfect-freehand 项目，以解决笔画粗头和不平顺的问题

设置中的默认笔宽滑杆范围为 4–24 px，每档 2 px；每次进入标注会话时使用保存的默认笔宽。


## 倒计时与时钟
- Ctrl+3 呼出或退出，退出后重置为默认时长；在“设置 → 倒计时”修改快捷键、默认分钟数、圆环/进度条样式与默认显示形态。
- 黑底全屏显示倒计时和下方当前时钟；透明悬浮窗可与标注同时显示，按住数字、圆环或内部空白区域拖动，滚轮调整大小。
- 使用右键菜单，在全屏和悬浮之间切换。Esc：退出计时并重置为默认时长。
- 计时窗口有焦点时，空格暂停/继续，↑ 加一分钟、↓ 减一分钟、← 减十秒、→ 加十秒，先增减再向下对齐至整分或整十秒（如 5:36 → ↑ 6:00、← 5:20、→ 5:40）；暂停时调整仍保持暂停。
- 到 00:00 后继续负计时，显示为 - 00:01、- 00:02……，强调色轻微呼吸提示，不发声音。
- R/G/B/O/Y/P/W 切换强调色，默认红色；双击计时窗口输入分钟数并重新开始。
- 圆环外部透明区域可点击穿透；圆环内部接收操作。右键可切换环形/条形样式和文字主题，位置、大小和样式随配置保存。

方向键调整后，以新的正剩余时间重建完整进度周期，约 150 毫秒平滑回到满圈/满进度条；负计时继续使用完整提示环，调整回正数后开启新周期。

悬浮窗右键可选“浅色文字”或“深色文字”，选择会保存；文字和进度图形附细反色描边，便于在不同桌面背景上阅读。全屏浅色文字配黑底，深色文字配浅底。

Ctrl+3 优先在鼠标所在屏幕呼出；悬浮窗跨屏呼出时保留相对位置与逻辑大小，跨 DPI 拖动时保持抓取位置。显示器断开后，窗口会移回可用屏幕。

计时窗口快捷键：A 切换全屏/悬浮窗，E 切换深浅色，C 切换环形/条形。全屏默认以原尺寸的 50% 显示，滚轮每格调整 5%，范围 25%–100%，独立保存；浮窗大小不受影响，条形样式在全屏时整体上移。

设置窗口按“缩放 / 标注 / 倒计时 / 关于”四个标签组织，底部为共用选项。切换标签保留输入，“保存”统一应用三个页面，“取消”放弃修改；倒计时右键“计时设置…”直接打开倒计时页，双击计时窗口仍可快速设置时长。
