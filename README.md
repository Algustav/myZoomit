# MyZoomIt
给演讲者、演示者的轻巧屏幕标注小工具。

这个小工具是我一直使用的[Zoomit](https://learn.microsoft.com/zh-cn/sysinternals/downloads/zoomit) 的现代改进版，轻量、快捷键驱动。
改为使用 Windows Ink 原生控件，使其笔画流畅度、系统兼容性优异（可参考office中的绘图工具）。

主要特点：
- 兼容电磁/电容笔（如surface系列笔记本/平板）、手指触控和鼠标绘制三种方式
- 使用win ink机制，笔画平滑流畅，能方便的擦除、撤销和重复
- 适配多屏幕和windows自带的屏幕放大镜（win+加号），兼容复杂的展示环境
- 为演示者优化的极简的快捷按键操作，减少屏幕视觉干扰
- 便携版且极小体积，exe文件不到 0.6 MB
- 免费，无需注册
- C++ ，MIT协议

只支持windows系统，兼容性在windows11 x64上验证通过，配置随程序文件夹携带。

## 使用说明
运行后程序在系统托盘常驻（图标可能位于隐藏图标区）

- 按下快捷键（默认Ctrl+2，个人习惯，可修改）进行标注，再次按下或Esc退出
- 用鼠标、触控笔或触摸屏幕绘制，均支持压感效果

- 按键1~5切换标注的图形模式：
  1手写，2矩形，3椭圆，4直线，5箭头
- 亦可配合修饰键快速绘制图形：
  Ctrl矩形，Tab椭圆，Shift直线，Ctrl+Shift箭头
- 按键切换笔迹颜色，共七种：
  R红色，G绿色，B蓝色，O橙色，Y黄色，P紫色，W白色

- Ctrl+滚轮：调整笔迹粗细(6~24px，默认12px)
- Ctrl+Z：撤销上一笔画或图形

- K：切换为纯黑背景，模拟在黑板上书写
- E：橡皮擦
- C：清空笔迹

- 退出标注状态会清空笔迹，如需要请按 PrtScr/PrtScn 键截屏保存

- 增加系统级的“鼠标强调”功能，用于打开系统设置“鼠标指针”项中的“按Ctrl显示鼠标位置”功能，能够有效引导观众注意力
- 增加“开机自动运行”功能

## 关于放大
- 放弃了截屏缩放功能，用户可自行使用windows自带放大镜（win+“加号”）
