# MyZoomIt

轻量、快捷键驱动的 Windows Ink 屏幕标注工具。

[下载 v1.6 便携版](https://github.com/Algustav/myZoomit/releases/download/v1.6/MyZoomIt-v1.6-win-x64.zip)。适用 Windows 11 x64，解压后双击运行；配置随程序文件夹携带。

当前版本：**v1.6 便携版**。发布说明见 [v1.6](docs/release-v1.6.md)。当前目录仅保留最新发布包，旧版本可从 Git 历史和 GitHub 历史发布中获取。

## 运行

双击 `build\MyZoomIt.exe`，程序在系统托盘常驻（图标可能位于隐藏图标区）。

- **Ctrl+2**：在鼠标所在屏幕开始 / 结束标注。
- **1 手写、2 矩形、3 椭圆、4 直线、5 箭头**：标注中按数字键选择工具。图形从按下处拖动到终点，实时预览，松开完成；鼠标、手指和触控笔均可使用。矩形和椭圆为空心边框；箭头指向按下的位置，拖动终点为箭尾。
- **按住 Ctrl：矩形；Tab：椭圆；Shift：直线；Ctrl+Shift：箭头**。松开快捷键恢复手写；若拖动中先松开按键，当前图形完成后恢复手写。Tab 在标注中不移动焦点。
- **Esc**：结束标注，恢复之前的应用焦点。
- **C**：清空笔迹。
- **E**：切换鼠标／手指橡皮擦，固定 12 的黑白双细边空心圆；触及笔迹即擦除整笔或整个图形。再次按 E 恢复原来的画笔颜色与粗细，选择图形或退出标注时退出橡皮擦。手指擦除时在触点显示圆圈，抬起后隐藏。
- **K**：切换纯黑黑板背景，保留已有笔迹；再次按下恢复透明背景。退出标注后重置，下次进入默认透明；清除笔迹不改变背景。
- **Ctrl+Z**：撤销上一次绘制、擦除或清空操作，可连续撤销；无撤销记录时不做操作。
- **Ctrl+Y**：恢复撤销的操作，可连续恢复。绘制、连续擦除和清空均可撤销／恢复；进行新的修改后清除旧的恢复记录。退出标注时清空记录。
- **Ctrl+鼠标滚轮**：调节笔宽，范围 6–24，每格调整 1；默认 12，开启悬浮状态菜单后显示当前宽度。只影响后续笔画。
- 鼠标左键、触控笔或手指：红色笔书写；触控笔保留压感。
- 鼠标和手指手写使用 perfect-freehand 算法模拟粗细，改善起笔与转弯平滑度；鼠标显示粗细系数为 0.8，电磁笔保留原生压感。详见 [v1.6 说明](docs/release-v1.6.md)。
- **R 红色、G 绿色、O 橙色、P 粉紫色、B 蓝色、W 白色、Y 黄色**：标注时按对应字母切换颜色，只影响后续笔画；开启悬浮状态菜单后显示当前颜色。
- 结束标注后再次进入，保留颜色、笔宽和所选工具；正常退出标注或退出程序时写入程序旁的 settings.ini，重启和复制文件夹后保留。
- 托盘左击或右击：开始 / 结束、设置、关于、退出。设置中可修改或删除全局快捷键、恢复默认 Ctrl+2，并查看操作说明。快捷键保存至程序旁的 `settings.ini`，重启后继续有效；冲突时保留旧快捷键。

快捷键输入框记录实际 Ctrl / Alt 组合，不自动补 Ctrl。编辑设置期间暂停全局快捷键，关闭设置后恢复。点击“删除”再保存可停用快捷键，重启后保持停用；仍可用托盘菜单进入标注。取消不应用修改。

标注期间覆盖层接收输入，不能点击底层应用；按 Esc 后恢复操作。每次结束标注（Esc、Ctrl+2、失焦或退出程序）都清空全部墨迹，重新呼出从空画布开始。没有缩放或笔迹保存功能。

## 构建与验证

运行 `scripts\build.cmd` 生成 Release 程序和 `build\build.log`。没有额外包下载。

当前版本不包含内嵌桌面输入测试或实验回退参数。绘制效果由用户手工确认。

[验收结果与已知限制](docs/milestone-1-verification.md)

- [v0.1 里程碑设计与验收清单](docs/milestone-1.md)
- [v0.2 图形绘制与验收记录](docs/milestone-2.md)
- 环境检查：在项目目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check-environment.ps1`。此参数只作用于本次检查进程，不修改系统执行策略。

最小开发环境只选择微软 C++ Build Tools 的 MSVC x64/x86 编译工具和 Windows 11 SDK，让安装器补齐必要依赖；无需 Visual Studio IDE、CMake 或额外工作负载。运行原型使用 Windows 11 x64 自带 XAML/Ink 系统组件。

实际编译与 Windows Ink 宿主检查：运行 `scripts\verify-toolchain.cmd`。

应用、托盘与设置窗口使用用户指定的霓虹彩色铅笔 Logo，外围白底已透明化。图标内嵌于程序，源文件与处理记录见 assets/README.md。

设置新增“显示悬浮状态菜单”和“开机自动运行”，默认均关闭。勾选并保存后生效，取消不应用修改。悬浮菜单开启时，图形快捷键单独位于第二行。开机自启仅作用于当前 Windows 用户，登录后在托盘运行。

设置中的“鼠标强调”控制 Windows 自带的“按 Ctrl 显示鼠标位置”。打开设置时读取系统当前状态，保存后全局生效并由 Windows 持久保存；取消不改变系统设置，不随便携配置迁移到其他电脑。

标注时鼠标变为当前笔色的圆点，圆点直径与笔宽同步，带细对比边缘。进入时约 180 毫秒从直径 200 缩小至当前笔宽；落笔立即结束动画，退出恢复普通指针。圆点按屏幕 DPI 缩放，中心为落笔位置。

## v1.6 便携版

复制完整发布文件夹到可写目录，双击 MyZoomIt.exe 即可运行。快捷键、悬浮菜单、画笔颜色/粗细/工具保存在同目录 settings.ini，按程序路径定位，与启动时的工作目录无关。Windows 11 x64 自带 Ink/XAML 组件，无需额外安装运行库。开机自启属于当前电脑的注册表配置，不会随文件夹自动启用；移动已开启自启的程序前先关闭自启，移动后需要时重新勾选。快捷键被其他程序占用时可从托盘修改。

“关于”窗口显示当前版本、项目地址、联系邮箱、语言、协议和作者信息；项目地址、邮箱和 perfect-freehand 致谢地址可点击打开。
