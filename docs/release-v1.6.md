# MyZoomIt v1.6

Windows 11 x64 便携版。解压到可写目录，双击 MyZoomIt.exe；升级前退出旧程序，保留自己的 settings.ini。

- 鼠标与手指使用 perfect-freehand 模拟压感和平滑笔迹，鼠标粗细补偿 0.8；电磁笔保留原生压感，图形粗细补偿 0.6。
- E 切换鼠标／手指整笔橡皮擦，使用固定 12 的黑白双细边空心圆；电磁笔末端擦除继续可用。
- Ctrl+Z 撤销、Ctrl+Y 恢复，支持绘制、擦除和清空操作。
- K 切换黑板背景；修正进入标注时任务栏消失的问题。
- 托盘左右单击均打开菜单；设置布局紧凑，新增系统鼠标强调开关。
- 关于窗口显示动态版本号，支持项目、邮箱及 perfect-freehand 致谢链接。

包内包含默认配置、使用说明和 MIT 许可证。鼠标强调和开机自启属于当前电脑设置，不随便携文件夹迁移。

开发过程由用户手工确认绘制及界面效果；发布程序已完成 Release 编译，本次打包不执行自动或桌面绘制测试。一次接收一个鼠标或手指手写指针；鼠标／手指笔迹层位于电磁笔原生墨迹层上方。
