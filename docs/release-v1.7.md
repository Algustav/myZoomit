# MyZoomIt v1.7

Windows 11 x64 便携版。解压到可写目录，双击 MyZoomIt.exe；升级前退出旧程序，保留自己的 settings.ini。

修正 Edge 全屏时呼出标注导致任务栏出现的问题：在激活标注窗口前，根据原窗口所在屏幕及内容区域判断全屏状态。全屏场景让标注窗口按全屏处理，普通桌面和最大化窗口保留任务栏；退出后恢复默认处理方式。覆盖 Edge F11 全屏和 PowerPoint 放映这两个常用场景。

保留 v1.6 的平滑压感笔迹、图形、整笔橡皮擦、撤销／恢复、黑板背景和便携设置。包内包含默认配置、使用说明及 MIT 许可证。

本次修正已由用户手工确认；发布程序进行 Release 编译，打包只检查压缩包完整性和程序版本，不执行自动或桌面绘制测试。
