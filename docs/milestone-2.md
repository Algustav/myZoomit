# MyZoomIt v0.2：快捷图形绘制

## 范围与操作

标注中通过无修饰的数字键选择工具：1 手写、2 矩形、3 椭圆、4 直线、5 箭头。选择后可连续绘制相同类型，按 1 返回手写。矩形与椭圆是空心边框；箭头指向鼠标按下的位置，拖动终点是箭尾。拖动提供实时预览，松开提交，点击而不拖动不产生图形。工具选择保留至退出程序。

沿用现有颜色快捷键及 Ctrl+滚轮笔宽调整。每个图形使用开始拖动时的颜色和宽度，固定线宽；手写保留原来的真实笔压。Ctrl+Z 一次撤销一个完整图形或手写笔画，按绘制顺序撤销。正在拖动时 Ctrl+Z 取消预览；C、退出标注、失焦、输入取消均清理未完成预览。退出标注清空所有笔迹和图形。

托盘设置仍是唯一设置入口，操作说明增加图形快捷键。全局标注快捷键仍可自定义，默认 Ctrl+2。数字键只在标注模式中生效。

## 实现

在原有 InkCanvas 上叠加透明 Canvas 接收图形模式的指针输入，支持鼠标左键、手指和触控笔。使用 XAML Polyline 实时预览并捕获当前指针，防止拖出边界丢失结束事件；忽略额外指针。失去捕获时取消未提交图形。

通过系统 InkStrokeBuilder 将图形路径创建成单个 InkStroke，加入原有 StrokeContainer。矩形使用闭合折线，椭圆按尺寸采样闭合轮廓，直线使用两端点；箭头用折返路径连接箭杆和两侧箭翼，因此一个箭头仍是一次撤销单位。图形关闭压感、曲线拟合与速度压感，避免直角被平滑；手写属性独立保留。

参考微软官方 [InkDrawingAttributes](https://learn.microsoft.com/uwp/api/windows.ui.input.inking.inkdrawingattributes) 与 [指针捕获](https://learn.microsoft.com/uwp/api/windows.ui.xaml.uielement.capturepointer) 说明。

## 按住快捷键临时绘制

按住 Ctrl 绘制矩形、Tab 绘制椭圆、Shift 绘制直线、Ctrl+Shift 绘制箭头；松开恢复手写。组合键优先级为 Ctrl+Shift、Tab、Ctrl、Shift。拖动开始后固定当前图形类型，先松开键也不会改变正在绘制的图形；指针松开后应用手写状态。Tab 被作为绘制修饰键处理，不移动焦点。数字键方式继续可用。退出或失焦清除临时工具状态。Ctrl+滚轮和 Ctrl+Z 保留原有操作。

按住快捷键新增验收通过：四种按键选择、拖动中松键保持形状、完成后恢复手写。完整桌面回归 result=0，Ctrl+滚轮、Ctrl+Z、触摸与颜色功能均通过，Release 构建无警告。
