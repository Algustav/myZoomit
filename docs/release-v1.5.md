# MyZoomIt v1.5

Windows 11 x64 便携版。鼠标和手指采用 perfect-freehand 默认圆头算法的 C++ 适配，修正快速起笔粗头与转弯不平滑问题；长笔画分段更新。鼠标最终显示粗细补偿系数为 0.8，手指为 1；电磁笔继续使用 Windows Ink 真实压感。

保留快捷键、颜色、笔宽、图形工具、整笔撤销、清除和便携设置。不新增算法参数入口。一次接收一个鼠标或手指手写指针；鼠标/手指笔迹层位于电磁笔原生墨迹层上方。

清理旧实验回退入口、原生鼠标回退分支、逐笔诊断日志、内嵌桌面输入测试及其参数。清理前的完整源码、程序和设置备份保存于本地 `output/backups/pre-v1.5-cleanup-20261001/current-version.zip`；旧发布版本保留。

用户已手工确认清理前鼠标、手指效果和 0.8 粗细补偿。整理后的版本只进行 Release 编译，未重新执行自动或桌面绘制测试。

便携包解压到可写目录，双击 MyZoomIt.exe。升级时退出旧程序并保留自己的 settings.ini。算法来源与 MIT 许可证随源码和程序包保留。
