# MyZoomIt v2.0

Windows 11 x64 便携版。解压到可写目录，运行 MyZoomIt.exe；升级前退出旧程序，保留自己的 settings.ini。

## 更新

- Ctrl+1 截图缩放：先冻结画面再标注，保留菜单与悬停内容。默认 200%，滚轮以 25% 缩放；第一次接触仅进入标注，右键返回浏览。
- Ctrl+2 实时标注：默认笔宽可设置，笔/触摸输入时隐藏光标，退出自动复制最终画面。
- Ctrl+3 倒计时：圆环与条形样式、当前时钟、全屏与可拖动透明浮窗、深浅配色、多屏与滚轮缩放。到时继续负计时，退出后重置。
- 计时窗口 A 切换全屏/浮窗，E 深浅色，C 样式，空格暂停；方向键调整分秒并对齐，调整后重新计算进度。
- 设置重组为缩放、标注、倒计时、关于四页；保留原关于窗口及托盘入口。快捷键输入只接受 Ctrl/Alt 组合，Backspace/Delete 清空。
- 统一更新版本号为 2.0。

## 发布文件

- MyZoomIt-v2.0-win-x64.zip：程序、干净默认配置、中文说明及许可证。
- MyZoomIt-v2.0-source.zip：源码、构建/测试脚本、文档及依赖许可。
- SHA256SUMS.txt：便携包文件与 ZIP 的 SHA-256 校验值。

默认 Ctrl+1 / Ctrl+2 / Ctrl+3，笔宽 8 px、缩放 200%、倒计时 10 分钟。原有个人配置不写入发布包。
