# MyZoomIt v1.0 便携版

发布日期：2026-10-01。适用 Windows 11 x64，使用 Windows 自带 Ink/XAML；C++ 运行库静态链接，程序无需额外 DLL、安装器或管理员权限。运行包只包含程序、同目录配置、使用说明和版本文件。

## 配置与迁移

配置固定为 MyZoomIt.exe 旁的 settings.ini，不依赖当前工作目录或 AppData。快捷键、悬浮菜单及正常退出时的画笔颜色/粗细/工具随文件夹复制。此次本机原 AppData 快捷键配置已迁移到 build/settings.ini；旧文件保留。发布默认 Ctrl+2、红色、宽度 12、手写，悬浮菜单关闭。

开机自动运行属于每台电脑当前用户的 Run 注册表配置。只有该项明确指向当前可执行文件时才显示为启用；复制目录不会继承另一份程序的自启状态，关闭时不删除其他路径的自启项。移动前关闭自启，移动后按需重新开启。

## 发布验收

- Release 编译无警告，文件版本、产品版本和清单版本为 1.0。
- 可执行文件导入项仅包含 Windows 系统 DLL/API 集，无 MSVC 外部运行库。
- 完整桌面回归退出码 0、result=0；独立指针专测退出码 0、result=0。
- 两个包含中文和空格的独立拷贝目录，从与程序目录不同的临时工作目录运行 --portable-test 均通过：Ctrl+Alt+9、悬浮菜单开启、宽度18、粉紫色、椭圆配置一致，并写回各自相邻的 settings.ini。
- 从第二个独立目录启动复制的程序并完成 Ink/XAML 指针专测，正常启动、所有模式隐藏及退出恢复通过。
- v0.1 发布快照保留不变。没有第二台实体电脑的测试条件，跨电脑结论限于相同系统架构及自带组件；此处实际完成的是本机跨目录、工作目录和配置迁移验证。

发布目录含便携运行包 ZIP、源码 ZIP、SHA-256 校验、构建和验收记录。本次发布为本地正式发布，未上传外部网站，也未生成 Git 标签（项目当前没有 Git 仓库）。
